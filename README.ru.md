# Codex Silver Startup · Аниме-персонаж ChatGPT
[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Русский](README.ru.md)

Анимация запуска и видео с женским аниме-персонажем, олицетворяющим ChatGPT, для **Windows Codex**. Распакуйте портативную сборку и запустите **Start Codex.exe**. Изображения и видео уже включены; при желании их можно заменить своими.

[Скачать версию для Windows](https://github.com/Eri-Kashiwagi/Codex-Silver-Startup/releases/latest) · [Исходный код](https://github.com/Eri-Kashiwagi/Codex-Silver-Startup)

## Начало работы

1. Установите официальную версию Codex из Microsoft Store / MSIX и откройте её один раз для первоначальной настройки.
2. Скачайте файл с окончанием `windows-x64.zip`. В свойствах ZIP нажмите «Разблокировать», если такой пункт есть, затем полностью распакуйте папку.
3. Сохраните работу и полностью завершите Codex через меню или значок в области уведомлений.
4. Откройте **Start Codex.exe**.
5. Запустите **Animation Settings.exe** или нажмите **Ctrl+Alt+B** в Codex, чтобы изменить язык, изображения, текст и видео.

Храните все файлы вместе. Архив `source.zip` предназначен для разработки; для обычного использования выбирайте сборку для Windows.

## Языки и настройки

**Язык по умолчанию — английский.** Интерфейс поддерживает английский, упрощённый и традиционный китайский, японский и русский. Выберите язык в **Language** и нажмите «Сохранить и посмотреть». Закрытие настроек отменяет несохранённые изменения. Введённый вами текст сохраняется без перевода при смене языка.

Начальная анимация длится около 12 секунд; её можно пропустить клавишей Esc. Затем видео персонажа воспроизводится один раз. При скрытии окна оно приостанавливается, а при возвращении продолжается. После завершения фон плавно исчезает и восстанавливается прежний вид.

Допустимый размер изображения — до 30 МиБ, видео MP4 / WebM — до 64 МиБ. Рекомендуется H.264 MP4. Начальные изображения и последующее видео настраиваются отдельно. Личные материалы хранятся на устройстве. Встроенное видео без звука.

Для восстановления интерфейса выберите «Отключить оформление и восстановить Codex». Чтобы вернуться к обычному сеансу, полностью завершите Codex и откройте его через официальный значок. Папка официальной установки и ярлыки не изменяются.

## Требования

Windows 10/11 x64, .NET Framework 4.x и официальная версия Codex из Microsoft Store / MSIX. Используется официальный Node с проверкой подписи; отдельно устанавливать Node, Python или FFmpeg не требуется.

EXE собраны локально и не имеют цифровой подписи. Для интеграции открывается случайный отладочный порт на loopback-интерфейсе. Он доступен локальным процессам до завершения Codex. Диагностика программы запуска выводится на английском, а анимация и настройки — на выбранном языке.

## Разработка и сборка

```powershell
node --test tools/*.test.mjs
powershell -NoProfile -File tools/build-release.ps1
powershell -NoProfile -File tools/verify-package.ps1
```

Для тестов нужен Node 22+. Сборка использует компилятор .NET Framework из Windows. Результаты сохраняются в `release/`; для повторной сборки укажите новый `-OutputDirectory`. Переводы находятся в отдельных файлах `locales/`; отсутствующие строки заменяются английскими. Внешний сервис перевода не используется.

[Заметки по разработке](docs/development.md) и [тестированию](docs/testing.md) доступны на упрощённом китайском.
