# 测试说明

## 自动化代码检查

开发环境需要 Node 22+，运行：

```powershell
node --test tools/*.test.mjs
```

检查范围包括官方主窗口筛选、回环地址约束、CDP 请求、设置和图片保存、GIF 保留、视频单次播放、暂停与恢复、结束回调及资源释放。测试数据使用虚构进程号、SID 和路径，不引用实际账号或会话。

语言检查覆盖五种语言的消息完整性、占位符一致性、HTML 消息引用、英文默认与回退，以及发行清单。浏览器检查应覆盖：首次默认英语、逐个切换语言、保存后重新打开、取消后恢复旧语言、重置时保留语言、保留自定义文字，以及较长的俄语文案在窄窗口中的排版。

## 构建与发行检查

在 Windows PowerShell 5.1 中运行：

```powershell
powershell -NoProfile -File tools/build-release.ps1
powershell -NoProfile -File tools/verify-package.ps1
```

构建只使用 project.json 中的明确文件清单。发行检查核对源码包和便携包的条目、SHA256、个人路径、常见密钥以及禁止纳入的本机数据目录。

打包使用统一 ZIP 时间戳，不携带原文件的本机修改时间。成功构建后，工具清理本次暂存目录；不要将原始开发工作目录当作发行包压缩。

## 真实窗口验证

模拟页面与自动化代码检查不等于真实 Codex 的最终视觉验收。原生窗口中还需检查：启动、设置、默认与自定义视频、跳过、视频结束后恢复原主题，以及不同窗口尺寸的输入框遮挡。

代码提供结束后的恢复逻辑；当前没有随仓库附带其原生窗口最终视觉验收记录。反馈问题时使用不含私人聊天的演示页面。

## 不纳入仓库的内容

个人测试报告、开发对话、机器配置记录、运行日志、调试端口、真实 PID/SID、浏览器配置、Cookie、账号文件和实机聊天截图不作为发行内容。Git 忽略规则是辅助措施，打包仍以明确清单为准。
